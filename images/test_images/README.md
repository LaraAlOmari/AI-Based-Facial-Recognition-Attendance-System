# Additional test photos

Use this folder if you keep a second set of test pictures, separate from `images/testimages/`. The original student photos are not included. They showed the same people under different lighting, angles, and distances, and they are omitted for privacy.

Add pictures of your own students. The filename has to match the code exactly:

`StudentName_ID_Number.jpg`

Examples:

- `SaraAli_100012345_1.jpg`
- `SaraAli_100012345_2.png`

`StudentName` is the student, `ID` is their number, and `Number` is the photo index. `.jpg`, `.jpeg`, and `.png` all work. Use that same pattern in `images/testimages/` and `images/confusionMatrixImages/` so every notebook cell can parse the files.
