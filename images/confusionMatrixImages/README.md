# Confusion-matrix photos

The original evaluation used pictures of students taken under different lighting, from different angles, and at different distances. Those photos are not in this folder. They are left out for privacy.

To run the confusion-matrix cell on your own class, add your students' photos here. Keep this filename, or the notebook cannot read the name and ID:

`StudentName_ID_Number.jpg`

Examples:

- `SaraAli_100012345_1.jpg`
- `SaraAli_100012345_2.jpg`
- `OmarNasser_100067890_1.png`

`StudentName` is the student. `ID` is their number. `Number` is which photo it is. `.jpg`, `.jpeg`, and `.png` all work. Use a new number for each extra photo of the same student. The evaluation cell reads every image in this folder and treats the ID in the filename as the true label.
