# Test photos

This folder is for test pictures of students. The original photos, taken under different lighting, angles, and distances, are not stored here. Student pictures are not posted.

Add your own students' photos to this folder when you want to try the identification tool. Every file needs the same name pattern the code expects:

`StudentName_ID_Number.jpg`

Examples:

- `SaraAli_100012345_1.jpg`
- `OmarNasser_100067890_1.jpeg`

`StudentName` is the student, `ID` is their number, and `Number` counts the photos of that student. `.jpg`, `.jpeg`, and `.png` are accepted. A file with a different pattern is skipped.
